# Deployment

Epic Stack is designed to be deployed to various platforms with minimal configuration.

## Fly.io Deployment

App and Admin deploy to Fly.io:

- Docker-based deployment
- Automatic scaling
- LiteFS for control-plane SQLite replication (US only)

## Cloudflare Deployment

The **CMS** and **jobs-cron** Worker deploy to **Cloudflare Workers** — not
Fly.io. The CMS uses OpenNext; jobs-cron uses Cron Triggers only.

`wrangler.jsonc` for CMS declares Cloudflare **D1** (SQLite) and **R2**
(media storage) bindings, but Payload isn't wired to use either yet;
it currently runs on local SQLite and local file storage in every
environment. See [CMS storage](https://github.com/mohammedzamakhan/epic-startup/blob/main/docs/cms-storage.md). The marketing
**Website** and **Sites** deploy to Cloudflare Pages.

Regional **tenant-api** (customer PII, per-org SQLite) deploys to **Oracle Cloud
Ampere** in Ashburn and Riyadh. See the repo docs:
[Deployment](https://github.com/mohammedzamakhan/epic-startup/blob/main/docs/deployment.md),
[Deployment checklist](https://github.com/mohammedzamakhan/epic-startup/blob/main/docs/deployment-checklist.md),
[Scheduled jobs](https://github.com/mohammedzamakhan/epic-startup/blob/main/docs/scheduled-jobs.md), and
[Tenant data residency](https://github.com/mohammedzamakhan/epic-startup/blob/main/docs/tenant-data-residency.md).

## Server Requirements

The application requires:

- Node.js 18+ (recommended: Node.js 20+)
- Dependencies listed in package.json
- Database (SQLite by default)

## Environment Variables

Key environment variables include:

- `SESSION_SECRET` - Required for secure sessions
- `DATABASE_URL` - Database connection string
- `INTERNAL_COMMAND_TOKEN` - App, tenant-api, and jobs-cron (internal POST auth)
- `MEDIA_TRANSFORM_BASE_URL` - App; Cloudflare video transforms (production)
- Various authentication provider keys (if using OAuth)

## CI/CD Pipeline

Epic Stack includes GitHub Actions workflows for:

- Testing
- Linting
- Type checking
- Automated deployments

## Monitoring

The stack includes built-in monitoring capabilities:

- Server-side logging
- Error tracking with Sentry integration
- Performance monitoring

## Database Backups

Database backup strategies are included for production deployments to ensure your data is safe and recoverable.
