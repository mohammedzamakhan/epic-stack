# Database

Epic Stack uses Drizzle ORM with SQLite as the default database.

## Drizzle ORM

Drizzle provides:

- Type-safe database access
- SQL migrations generated from the TypeScript schema
- Schema definition through TypeScript tables
- Powerful query capabilities

## Schema Structure

The default schema includes models for:

- Users
- Authentication (passwords, sessions)
- Notes (sample application)
- Permissions and roles
- Connections (for OAuth providers)
- Passkeys (WebAuthn)

## Migrations

Database migrations are handled through Drizzle:

```bash
npx drizzle-kit generate  # Create a migration in development
npm run db:migrate:deploy # Apply migrations in production
```

## Connection Pooling

In production, Epic Stack is configured with connection pooling for better performance and reliability.

## Data Access

Data access is provided through the shared Drizzle database client:

```typescript
import { db, User } from '@repo/database'
import { eq } from 'drizzle-orm'

// Query example
const [user] = await db.select().from(User).where(eq(User.id, userId)).limit(1)
```
