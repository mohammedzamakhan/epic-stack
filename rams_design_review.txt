[A11Y] apps/app/app/components/app-sidebar.tsx: Lines 285-325
  Hidden sidebar layers remain in accessibility tree
  <motion.div animate={{ opacity: isAccountRoute ? 1 : 0 }}>
  Issue: `opacity: 0` + `pointer-events: none` visually hides content but leaves it discoverable by screen readers.
  Fix: Add `aria-hidden={!isActive}` or `visibility: hidden` to the container when inactive.

  Issue: When the mobile menu opens, focus is not trapped within it. Keyboard users can tab into the background page content.
  Fix: Implement focus trap logic (e.g., using `focus-trap` library or manual event interception) when menu is open.
  WCAG: 2.1.2

SERIOUS (5 issues)
──────────────────
[A11Y] packages/ui/components/ui/sidebar.tsx: Line 186
  Sidebar rail is keyboard inaccessible
  <button tabIndex={-1} ...>
  Issue: `tabIndex={-1}` removes the sidebar resize handle from the tab order. Keyboard-only users cannot resize the sidebar.
  Fix: Remove `tabIndex={-1}` and ensure it has `role="separator"` or proper button semantics with keyboard handlers for resizing.
  WCAG: 2.1.1

[A11Y] packages/ui/components/icon.tsx: Line 36
  Icon potentially decorative but readable
  Issue: If `title` is missing, SVG does not default to `aria-hidden="true"`. It might be read as "image" or skipped inconsistently.
  Fix: Add `aria-hidden={!title}` or explicit `aria-hidden="true"` when no title is present.
  WCAG: 1.1.1

[Design] apps/app/app/components/forms.tsx: Line 31
  Text too small for readability
  <li class="text-[10px]">
  Issue: 10px font size in `ErrorList` is likely illegible for many users.
  Fix: Increase to `text-xs` (12px) or larger.
  WCAG: 1.4.3 (related)

[A11Y] packages/ui/components/status-button.tsx: Line 85
  Disabled state prevents focus
  <Button disabled={internalStatus === 'pending'}>
  Issue: Using `disabled` attribute removes the button from focus order. If a user submits and it becomes pending, focus is lost/reset to body.
  Fix: Use `aria-disabled="true"` and `preventDefault` in handler instead of `disabled` attribute to maintain focus.
  WCAG: 2.1.1

[A11Y] packages/ui/components/ui/checkbox.tsx: Line 11
  Touch target borderline
  Issue: Visual size is 16px. Touch area padding expands it to ~40px width, ~32px height.
  Fix: Increase pseudo-element padding to ensure 44x44px hit area.
  WCAG: 2.5.5
